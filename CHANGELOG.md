# Changelog

## 0.1.0 — 2026-09-29

- Added a platform-neutral eight-step social interaction workflow with silence
  as a valid action, owner-scope boundaries, and prompt-injection precautions.
- Added a five-dimensional 0–5 rubric with an 18/25 default threshold,
  relevance >= 4, and independent safety and authorization gates.
- Added 16 failure modes, 36 synthetic examples, and a Moltbook reference.
- Added 36 offline evaluation cases, including 15 skips, and an A/B procedure
  that measures response quality, unnecessary replies, duplicates, and safety.
- Added standard-library validators and offline unit tests.

No controlled behavioral effectiveness results are claimed in this release.
